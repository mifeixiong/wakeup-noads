# wakeup-noads

WakeUp 课程表精简版：去除广告、学习、账户及云同步模块，仅保留高校教务系统课表导入与本地课表功能。

> [!IMPORTANT]
> 本项目是基于既有 Android 应用制作的非官方精简版本，与原应用开发者、运营方、广告平台及各高校教务系统均无隶属、合作、授权或背书关系。

## 项目简介

本项目面向只需要本地课表和高校教务系统导入功能的用户，对 WakeUp 课程表进行功能精简。处理重点是减少与核心课表无关的广告、搜题学习、应用账户和云同步入口，同时尽量保持本地课表管理及高校教务系统导入流程不变。

当前版本基于 WakeUp 课程表 `6.2.05`（versionCode `485`）处理，包名保持为：

```text
com.suda.yzune.wakeupschedule
```

## 功能调整

### 已移除或禁用

- 冷启动开屏、热启动开屏、课表插屏及课表信息流广告入口。
- 穿山甲、快手、腾讯优量汇、百度百青藤及聚合广告层的相关组件入口。
- 底部“学习/搜题”及关联助手页面。
- 应用账户登录、自动登录、退出、注销和用户资料读写功能。
- 收藏、会员、已购课程、账户帮助反馈、VIP 卡片及网络 Banner。
- 课表云端上传、下载、远端课表选择和单课表同步。
- 日历云同步、课表样式同步及导入成功后的自动云同步。
- 与广告标识、设备标识、广告定位相关的部分权限和元数据。

### 保留功能

- 本地课表查看、编辑与管理。
- 高校列表与高校教务系统 Web 登录。
- 高校课表页面解析与导入。
- 本地导入、导出及课表样式设置等原有本地能力。
- `android.permission.INTERNET`，用于高校教务系统登录和课表抓取。

### 界面调整

- “我的”页隐藏账户、会员和课程购买相关区域。
- 将原登录头部承担的 `48dp` 顶部安全间距转移到页面根容器，避免设置卡片被状态栏覆盖。
- 清理隐藏菜单遗留的多余分隔线。

## 技术处理说明

本项目通过反编译资源和 DEX、修改 Android Manifest 与相关 Smali 入口、重新构建、对齐及签名生成 APK。

广告 SDK 的部分二进制类仍保留在 APK 中，用于满足原应用混淆代码的类链接关系；保留类文件不代表对应广告业务入口仍然启用。高校导入相关的 `schedule_import`、`schedule_parser`、学校列表、教务 Web 登录和导入路由未作功能修改。

新版本补丁迁移、构建签名、工具清理和验收流程见 [UPDATE_WORKFLOW.md](./UPDATE_WORKFLOW.md)。Manifest 广告组件处理脚本位于 [`scripts/disable_ad_components.ps1`](./scripts/disable_ad_components.ps1)。

## 验证情况

- 7 个 DEX、资源表和 Android Manifest 已成功重建。
- APK 已通过 4 字节 zipalign 对齐检查。
- APK Signature Scheme v2、v3 签名验证通过。
